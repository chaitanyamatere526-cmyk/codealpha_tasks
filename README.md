# Hotel Reservation System 🏨

## Project Overview
A Java-based console application developed as part of the **CodeAlpha Java Programming Internship – Task 4**. It allows users to search available hotel rooms, make and cancel reservations, simulate payments, and view booking details.

## Features
- Search available rooms.
- Room categories: Standard, Deluxe, and Suite.
- Book and cancel reservations.
- Simulate payment.
- View booking details and total cost.
- Store and retrieve bookings using File I/O.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling (File I/O)
- Scanner

## How to Run
Compile using `javac HotelReservationSystem.java` and run using `java HotelReservationSystem`.
